# Production provenance (inactive)
The prototype verifies an Ed25519 signature over the exact JSON serialization of a release record (schema, repository, environment, deployment, commit, digest). The digest covers sorted production file paths and SHA-256 contents, excluding preview. The signer must independently verify successful deployment and explicit owner approval before signing. Keep the private key outside PR jobs and repository; pin the public key and current approved deployment/commit in an independently controlled publisher. Never accept these trust inputs from candidate code. Retain the signed record and artifact in an immutable trusted store. A valid older signature is not sufficient: compare against the current trusted deployment identity. Use immutable extracted trees, safe archive extraction and serialized publishing; this helper does not implement these controls or a live deployment. Same-origin preview code can still access production storage; byte integrity does not imply browser isolation. No keys generated for production, no settings changed. Test fixtures generate ephemeral keys only.
